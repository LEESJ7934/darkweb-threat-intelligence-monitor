## 남은 한계와 면접 확인

- 프로젝트용 위험점수 L/I를 실제 조직에서 어떻게 구체화할지 설명 필요. 현재 문서에는 단계별 조직 정량 기준이 없음.
- 코드·테스트는 권한분리와 집계 기능의 증거이며 정기 운영·승인·위험수용의 증거는 아님.
- 개인정보 최소화·redaction은 완전한 PII 탐지나 법적 적용성 결론이 아님.
- MFA, 중앙/WORM 로그, 백업 복원 시험, NTP 운영증적, 조직 사고훈련은 미완료.
- 초기 팀 기간 2025.11~2025.12와 이후 개인적으로 정리한 자체 모의진단·후속 개선을 구분. 확인되지 않은 기여율·팀원 분담 수치 없음.
